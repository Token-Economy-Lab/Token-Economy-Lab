# 网页设计说明

## 使用者与目标

主要面向研究团队和后续加入的学生，兼顾合作方阅读。学习路径支持按顺序进入研究方向，技术专题支持按问题查阅，资料库和报告支持形成研究判断。

当前先完成网页与内容框架，再开展全面调研。所有“专题框架”页面说明调研范围，不代表已经完成综述。

## 页面草图

首页结构：顶部导航 → 标题与动态任务成本地图 → 需求/执行/产出三个观察层面 → 技术专题 → 基础笔记入口 → 学习/资料/报告入口。

阅读页结构：左侧章节导航 → 中间正文 → 右侧页内目录。手机端收起侧栏，正文按单列阅读。

密码页在解锁前独立显示，不包含正文预览或文献摘要。错误提示在表单内呈现，按钮在解密期间显示等待状态。

## 参考与取舍

- [Hugging Face 文档](https://huggingface.co/docs/hub/main/en/enterprise-tokens-management)：参考章节导航、正文宽度与页内目录。该页面的 Token 指访问凭据，不是模型推理 Token；不将其内容归入 Token 经济技术证据。
- [Belief Context Graph](https://bigai-nlco.github.io/bcg/)：参考清晰的模块层次和“概念与图示相互说明”的布局。
- [Graph of States](https://luoyu100.github.io/projects/graph-of-states/project/)：参考图形逐步出现、章节渐进进入、阅读进度和低干扰动效。仅借鉴设计原则，未复制其源码或论文图。

## 视觉与动效

白色阅读底、深色文字、青绿色主色，蓝色与浅金色区分计算侧与评价侧。英文主标题采用衬线字体，中文正文采用系统无衬线字体，编号与元数据采用等宽字体。避免网络字体依赖。

首页成本地图一次播放约 2.4 秒，逐步形成任务与技术方向的连接。它是概念图，明确标注非实测数据。支持重新播放，不持续循环。章节进入视口时轻微上移并显现。阅读页提供进度与目录高亮。

正文基础字号 16px，阅读行距约 1.95。动效尊重 `prefers-reduced-motion`，不作为获取内容的前置步骤。菜单、解锁表单和锁定按钮支持键盘操作。

## 技术选择

采用 Astro 静态生成与 Markdown 内容集合，使用自定义主题。没有直接套用通用文档主题，以便首页保留研究地图的表达，同时让正文保持文档布局。

使用 StatiCrypt 加密每个静态 HTML，保持 GitHub Pages 静态部署能力。公开代码、私有正文和公开密文分别存放在独立组织的三个仓库中，发布仓库不保存正文源文件。

## 继续迭代

完成设计评审后，逐步填入经核验资料。在论文条目达到可用规模后再加入分类筛选和加密搜索索引，避免先构建无法产生有效结果的搜索界面。
